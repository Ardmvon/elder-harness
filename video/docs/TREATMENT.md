# 《银龄智办》演示片 · treatment & 风格圣经

> 参考片形态（`abstract-algebra-promo`）：**分章解说片**，1920×1080，中英双语字幕，
> 章节标题 + 数据 + 拟研发标注，Python 合成配乐与音效，按 cue 表与画面同步。
> 本片沿用这套"解说片语法"，但内容全部来自本仓库的真实实现与实测记录。

## 一句话

**老人说出一件事，助手跨应用替他办；关键的决定，始终留在他自己手里。**

全片由一条**证据线**贯穿：每一次助手说"办好了"，画面都要交代这结论是从哪一步、
哪个页面、哪一次输入来的。说不清的地方，画面就停下来，而不是编一个圆满的结局。

## 语气

- **冷静、可信、不煽情**：像一位有经验的接线员在解释自己的工作，而不是广告。
- **先给画面，再给结论**：每个机制先演一遍，再上一行字幕。字幕是注脚，不是旁白。
- **讲边界**：哪些做到了、哪些只是原型、哪些是拟研发，画面和字幕都要能分得清。
- **不要**：AI 感的粒子星云、发光大脑、紫色霓虹、赛博雨；不要给虚构的成功画面。
- **幽默要克制**：只在真实细节上（盲页面只能靠截图、10 步任务 0 次打扰）轻轻带一下。

## 字体与排版（ra1 语法）

- 中文：**Noto Serif CJK SC**（衬线，标题与字幕）；手机屏内仍用 Noto Sans CJK SC（与 App 一致）。
- 英文副题：**Liberation Serif Italic**；章节英文小字用衬线 + 5px 字距大写。
- 章节号：衬线粗体，金色 `#E2BD6B`。
- 屏幕内文字最小 **40px（1080p）**；手机屏 caption 自动收缩以适配圆内。
- 字幕：中文 42px/700 白，英文 27px italic `#DDD5C4`，下方 0.42 单位高的黑色渐变，
  位置固定在画面下缘，英文比中文晚 80ms 出现。

## 字幕规则

- **中英双语**：中文承接信息，英文给出一句等价表达（不是逐字直译）。
- 每个镜头在源码里用本地秒声明 `subs: [[a, b, zh, en]]`；时间轴聚合成全局字幕，
  页面与 cue 表都从这一份数据派生。
- 字幕只在画面已经说明白之后出现；不允许字幕先说结论、画面再做。
- 最小停留 1.2s；单条中文不超过 18 字，英文不超过 68 字符（单行不折行）。

## 逐章 treatment

### 序 · 开机（0:00–0:14）
黑场中一点绿光呼吸。粒子从四周被吸入，聚成一条悬空的阿基米德螺旋，12 个节点亮起——
每个节点是一次真机跑过的任务。镜头沿螺旋轴缓推；粒子化出片名，再散回螺旋交给下一章。
- 字幕：「银龄智办 / A trustworthy cross-app assistant for older people.」
- cue：`riser`（起）→ `chime`（片名）→ `whoosh`（交接）。
- 数据：12 个节点取自 `docs/status.md` 真机任务表。

### Ⅰ · 说得出口（0:14–0:40）
螺旋收成手机浮板：一屏只有状态行、一个大圆按钮、一行提示。按钮从绿变橙＝麦克风打开。
声波环离屏；助手说话时声波被从内侧打断、反相、变橙——插话立刻闭嘴。随后助手说的每一步
以磨砂 pill 逐条滑出（"正在打开微信"…），当前一条最亮。
- 字幕：「说得进去，也插得进去 / You can talk over it — and it stops.」
- cue：`whoosh`×2 → `cut`（打断）→ `whoosh`（接管）；`tap`/`click`（按键）。
- 数据：`README`「语音与打断」表；盲页面键盘编号来自 `docs/status.md`。

### Ⅱ · 看得见页面（0:40–1:06）
浮板上无障碍树被抽出：带文字的节点升为发光文字块，细线连成三层结构（看见）。
随后树整体 alpha 塌到 0，只剩位置残影，浮板布满噪点——读不到控件（也看得见看不见的时候）。
背面浮出一张截图被送进管线；坐标网格叠上去，编号点按。
- 字幕：「树里没有的，截图里有 / When the tree is empty, the screenshot answers.」
- 数据：`喜鹊儿课表：树里只有节次与日期，没有课程名`（`docs/status.md`）。
- 母题：无障碍树（全片复用）、`uBlind` uniform。

### Ⅲ · 办得成事（1:06–1:36）
镜头拉远，浮板缩成涡旋中心一粒；节点文字、对话记录、工具目录汇成发光文本带卷入涡旋，
吐出 `tap` / `input_text` / `screenshot`。工具方块被执行后回灌新页面，循环闭合。
- 字幕：「看见 → 规划 → 执行 → 再看一眼 / Observe, plan, act, observe again.」
- 数据：工具目录与循环来自 `harness/Harness.kt`。

### Ⅳ · 办成有证据（1:36–2:06）
涡旋吐出一句声明，落在玻璃卡上：「已帮您把消息发出去了…时间是 17:37，发送成功」。
卡背透出这一轮真实动作序列：只有 `open_app / wait / tap_xy / screenshot`。
三道细密光栅扫过，依次亮起**文字来源 / 时间锚点 / 改变类动作**（`OutcomeCheck` R1–R3）。
卡片沿缝炸裂，碎片吹散；灰里浮起诚实的收尾：「我没法确认这件事真的办成了」+「接着办」。
一个只读任务（查课表）的诚实结论顺利穿过光栅，落入白卡，边框转 `good`。
- 字幕：「说不成，也做不成 / It cannot claim what it did not do.」
- 数据：`Harness.kt` L713 的真实翻车样例与 R1–R3（`core/…/OutcomeCheck.kt`）。
- 克制：只写"挡得住物理上不可能的声明"，不写"已解决谎报"。

### Ⅴ · 帮忙有分寸（2:06–2:32）
镜头升起，浮板前三级台阶，每级一条颜色光带。工具方块沿台阶上行：
① 绿：点击/输入/滚动/返回 → 直接穿过（一闪而过，不给特写）；
② 橙：`tap_xy` → 浮出"确认一次"卡片，老人点一下后放行，同任务不再问；
③ 红：付款/下单/发送/验证码 → 方块在台阶前停住并退回，一只手从侧面把它接走。
- 字幕：「能做的做完，不能做的留给本人 / Do what it can; hand back what it must not.」
- 数据：实测 10 步外卖：**打扰 0 次**、直接执行 9 次、危险步骤 1 次被拒并交回（`docs/status.md`）。

### Ⅵ · 交还本人（2:32–2:52）
三条真机案例并置：美团结算页说清金额/地址/点哪里后交给老人；QQ 填好后请老人自己发送；
拼多多跳到第三方支付页时在盲页面上取消支付并返回。镜头始终停在"交接点"，不越过。
- 字幕：「关键一步，本人来按 / The last step stays with the person.」
- 数据：`docs/status.md` 真机任务表；规则来源 `README`「什么会停下来问老人」。

### Ⅶ · 可信的人（2:52–3:16）
从浮板射出一条发丝般的连线，穿过星空落到三个大小不同的星点：家人（最大）、社区网格员、邻居。
求助卡片沿连线飞去，一个星点亮起并回推"我来处理"。卡片飞过时，页面上可能含隐私的内容
被一个磨砂罩挡住。
- 字幕三行依次亮起：「角色决定能看到什么」「只有家人能给老人留话」「不做远程控制」。
- 数据：`server/app/web.py` 的 `VISIBLE_KINDS`；`README`「可信圈子」。

### Ⅷ · 家人教一次（3:16–3:32）—— **拟研发，必须标注**
训练台视角：家人示范的一段操作被拆成带参数的语义步骤，附上页面前置条件与目标状态；
一条候选技能作为半透明虚线被提出，复用时会根据当前页面重新定位与校验。
- 字幕：「教一次，但要按现在的页面重找 / Taught once, re-located every time.」
- 标注：角标「拟研发方向」+ 虚线边框 + 低饱和；与已实现章节区分。

### Ⅸ · 越用越会办（3:32–3:54）—— **拟研发，必须标注**
一次失败的快递任务轨迹被拆成节点，卡点在"误入推广入口"处发红。候选路径包住卡点，
送进验证：脱敏快照回放 → 不同布局 → 旧任务回归，三次脉冲依次亮绿，虚线凝实并获得启用徽章。
远端另一条路径退化变灰，被"回退"徽章替换回旧版本。
- 字幕：「验证过再启用，退化就退回去 / Verify before enabling; roll back on regression.」
- 数据：`README`「技能如何自进化」；明确标注尚未实现。

### Ⅹ · 收束（3:54–4:10）
所有元素回撤，手机浮板回到画面中心并稳住；四周的光收成一条绿色地平线。数据以极简排版逐条落定：
真机任务记录 · 回归校验 JVM 73 项 + 服务端 20 项 · 缓存命中 93%（单次 10 步任务，恢复后第 1 步）·
插话打断与步骤播报已实测。落点单独占满一屏、静止 1.5s：
**办成有证据，帮忙有分寸**。
- 字幕：「办成有证据，帮忙有分寸 / Evidence for what it claims; restraint in what it does.」

## 母题（全片复用，避免每章自造方言）

1. **手机浮板**：页面层。屏幕是真实 Canvas 烘焙，与 App 同排版。
2. **无障碍树**：抽象层。发光节点 + 细线，`uBlind` 控制"变盲"。
3. **证据光栅**：约束层。三道闸门是片子的辨识度——别的片子拍推理有多强，这部拍约束在哪生效。
4. **台阶**：分级自主。绿/橙/红三级。
5. **可信圈**：连线 + 星点 + 隐私罩。
6. **技能骨架**：虚线路径 + 验证脉冲 + 版本徽章（拟）。

## 技术约定

- **确定性**：画面与字幕都是 `t` 的纯函数；随机用 `mulberry32/hash`；逐帧抖动用帧号，不用 `Math.random`。
- **运动模糊**：每个镜头声明 `mb`（3–4 子帧）。导出时每帧在快门下取 K 个子帧
  （`t + ((k+0.5)/K - 0.5) × shutter/fps`），每个子帧走完全相同的单帧渲染路径，再用 2D
  canvas 的 `lighter` 以 1/K 平均，最后叠 overlay。跨硬切自动退回单帧（子帧落在别的镜头时拉回 t）。
  - 正确性判据：`shutter=0` 且关闭抖动时，4 子帧结果必须与单帧逐像素差 ≤2/255。
  - 命令：`node render/frames.mjs --mb --shutter 0.5`；预览与静帧默认单帧。
  - 成本：约 K 倍渲染时间。250s × 60fps 约 15000 帧，建议 GPU 后端（`GL_BACKEND=gl-egl`）分段渲染。
- **HITS**：镜头声明 `hits: [[localSeconds, k]]`，全片统一闪光与相机轻踢；字幕不抖。
- **字幕与 cue 单一来源**：镜头声明 → `timeline.js` 聚合 → 页面表现层 + `cues.json` → `music.py`。
- **审片管线**：`stills → sheet → 短视频 → perf`；改完必须看图，不能只信代码。
- **交付**：`build.py` 把 `music.mp3` 内联进单文件 HTML；母版走 `render/frames.mjs` + `encode.mjs`。

## 素材边界与合规

- 画面中所有数字、文案来自 `README.md` / `docs/status.md`；**拟研发一律带「拟」标记或虚线边框**。
- 不出现真实姓名、手机号、完整住址、验证码、余额、订单号；真机录屏避开结算/支付页。
- 参赛材料匿名：不出现学校名称、Logo、指导教师信息。
- "可信"是设计目标；不把"通过机械检查"写成"结果已经核实"。已知边界见 `README`。
