# 《银龄智办》演示片 · 分镜脚本 v2（250s）

技术形态：Three.js（WebGL2）+ GLSL，离屏逐帧 + ffmpeg
画幅：1920×1080 · 60fps · **总长 250.0s**
时间尺：96 BPM，拍 0.625s，小节 2.5s，**100 拍 = 250.0s**（拍只是尺子，不是节奏装置）
旁白：无。**中英双语字幕 + 屏幕内文字**承担信息
素材边界：数字与文案来自 `README.md` / `docs/status.md`；拟研发带「拟」标记或虚线边框

> **v2 的三处改动**
> 1. **删掉一切节拍装置**：没有 HITS 闪光表、没有"每 0.5 拍闪切"、没有"落拍硬切"。
>    节奏由内容给，不由节拍器给。
> 2. **运镜变活，但不抖**：新增运镜库（横移/升降/环绕/跟拍/推细节/拉揭示），
>    每条都是单段缓入缓出、**刻间不停机**，并且**禁止手持噪声、禁止抖动、禁止 roll 漂移**。
> 3. **切点全部改为形变衔接**：前一镜的物体变成后一镜的物体，相机动量跨切点延续，
>    全片没有一处"停下来再开始"。

## 一、运镜库（只有这些，且都不抖动）

| 名称 | 运动 | 用在哪 |
|---|---|---|
| `dollyIn(k)` / `dollyOut(k)` | 沿视线推近 / 拉远 | 进细节、退全局 |
| `craneUp(k)` / `craneDown(k)` | 升降，带轻微俯仰 | 揭开空间、压低情绪 |
| `truckX(k)` | 横向平移（前景产生视差） | 三段并置、横移转场 |
| `orbit(target, deg)` | 绕主体环绕 | 看物体的另一面 |
| `follow(target, k)` | 跟随运动物体 | 方块上行、卡片飞行 |
| `pushToDetail(target)` | 推近到某个细节充满画面 | 切点入口 |
| `pullToReveal(target)` | 从细节拉远揭示全貌 | 切点出口 |

**规则**：每镜只用 1–2 个 move 叠加，全程一条连续曲线；**任何时刻相机速度不为 0 直到镜头结束**
（最后一个镜头除外）。强调只靠：**光、尺度、时间**——不靠抖、不靠拍点闪。

## 二、全局工艺标准

### 建模
- 手机：**圆角箱体**（有真实厚度）、金属中框（倒角高光）、玻璃前盖（菲涅尔边缘）、屏幕内嵌 0.4mm。
- 台阶：挤出几何，边缘有 0.3mm 倒角（受光才有"实物感"）。
- 卡片：有厚度的薄板，边缘 chamfer；玻璃卡是真的双面可见。
- 树/轨迹/虚线：GPU 线段（胶囊体），线宽随距离衰减，不给 1px 硬线。

### 材质
- 哑光金属、磨砂玻璃、哑光纸、自发光屏。**同一材质在全片只出现一次定义**。
- 屏幕永远是画面里最亮的东西；玻璃只反射"环境光"和"屏幕自身"两层，不做假反射贴图。

### 灯光
- 一盏左上主光（冷白，硬）、一盏 brand 绿轮廓光（从背后偏右）、地面反弹（极弱）、
  空气薄雾（让光有体积）。
- **bloom 只作用于 brand / attention / good 三种信号色**，其余保持清晰（正文与字幕绝不发光）。

### 动效
- 每个动作三段：**预备 → 动作 → 跟随**（follow-through）。没有一处"直接开始、直接停下"。
- 位移用 `EASE.out`，颜色/状态用 `EASE.inOut`，落定用阻尼弹簧（轻微过冲）。
- 次级运动：粒子、尘埃、波纹、纸角、光的呼吸——**每个画面至少有一处一直在动**。

### 转场（本片的辨识度）
**所有切点都是形变，不是硬切。** 每次切点由上一镜的某个物体变成下一镜的某个物体，
相机在切点两侧保持同一方向的速度：

| 切点 | 形变 |
|---|---|
| 序 → Ⅰ | 螺旋的粒子收束成手机轮廓；镜头沿螺旋轴继续推进，不停 |
| Ⅰ → Ⅱ | 镜头贴近屏幕，橙色光圈占满画面 → 直接穿屏，从光圈内部穿出到页面 |
| Ⅱ → Ⅲ | 截图的坐标网格线被抽走，变成涡旋的输入光带 |
| Ⅲ → Ⅳ | 涡旋中心吐出一张玻璃卡（Ⅲ 的工具方块化成卡片边缘） |
| Ⅳ → Ⅴ | 诚实白卡的边缘延伸成第一级台阶（good 绿连续） |
| Ⅴ → Ⅵ | 接走红方块的那只手，掌心托着方块 → 第一个交接点的手机 |
| Ⅵ → Ⅶ | 手离开画面，掌心方块化成一颗星点 → 星空后拉 |
| Ⅶ → Ⅷ | 连线的一端落到一张摊开的纸上 → 示范纸面 |
| Ⅷ → Ⅸ | 纸被推远成轨迹板（同一张纸，换了一张图） |
| Ⅸ → Ⅹ | 启用徽章飞起 → 变成收束里的一个数据点 |

## 五、小巧思清单（每条都要在画面里看得见）

1. 屏幕的光会落在地面上，地面随屏幕颜色（绿/橙）变化。
2. 按钮波纹在玻璃上有倒影，且倒影比本体慢 2 帧。
3. 声波环被切断的瞬间，助手那五条声纹不是消失，是**塌成一条直线**。
4. 无障碍树的每个节点带着一个极小的编号，编号在变盲时最后一个消失。
5. 坐标网格的编号字号，随置信度降低而变小。
6. 涡旋里的文本带，字符是可读的那几条真实工具名，其余是灰。
7. 玻璃卡碎裂后，碎片里有一块停在半空，随后才落下。
8. 台阶旁的计数器从 0 走到 9，**第 9 下之后停住**，不归零。
9. 手接走方块时，方块的内部光在掌心亮一下再灭。
10. 星点的「我来处理」回推时，字是手写感的，不是印刷体。
11. 磨砂罩落下时，罩子边缘有一圈极细的折射。
12. 纸上的墨迹在"拆解"时不是断成段，而是每段各自轻微鼓起。
13. 虚线重定位时，旧位置留下一层极淡的残影，然后淡掉。
14. 启用徽章的金属反光扫过时，徽章上的刻字先亮后亮底。
15. 收束时所有元素沿各自的来路退回，方向与来时完全一致。

## 六、技术约定

- **确定性**：画面与字幕都是 `t` 的纯函数；随机用 `mulberry32/hash`；**禁止 `Math.random()`**。
- **运动模糊**：每镜 3–4 子帧，快门下平均；跨切点退回单帧（不糊切点）。
- **切点不断流**：切点两侧相机同向同速，物体形变承接；`timeline` 里相邻镜的
  起止机位必须写成连续的（前镜末帧 = 后镜首帧）。
- **字幕与音效单一来源**：镜头声明 → 聚合 → 页面 + `cues.json` → 配乐脚本。
- **审片**：`stills → sheet → 短视频 → perf`。
